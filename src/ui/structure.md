# UI Module Structure`n`nThis folder contains the native rendering interface for Vrutti IDE. We use a GPU-accelerated approach to ensure the editor draws text extremely fast without blocking the system.`n`n## Files and Responsibilities`n`n* **`Window.h` / `Window.cpp`**: This handles creating the main application window on your operating system. It communicates with the graphics card (via OpenGL) and captures mouse and keyboard events.`n* **`EditorView.h` / `EditorView.cpp`**: This is responsible for drawing the text and user interface components. It uses lazy loading (virtualization), which means it only asks the computer memory for the specific lines of text that are currently visible on your screen. This allows you to open massive files instantly because the invisible text is never loaded into RAM.
