# Frontend Module

This directory contains the entire modern web frontend for Vrutti IDE, built with Lit Web Components and Vite.
It acts as the visual presentation layer running inside the embedded Chromium webview.

## Directories
- `src/`: Contains the TypeScript and Lit Custom Element definitions.
  - `main.ts`: The root Lit application component `<vrutti-app>`. Contains the custom HTML title bar, draggable header, and SVG logo.
- `dist/`: The output directory for the compiled single-file HTML/JS bundle generated by Vite.

## Build Process
The frontend is built inside a Docker container (`docker-compose.frontend.yml`) which runs `tsc && vite build --base ./` using the `vite-plugin-singlefile` to bundle everything into a single standalone `index.html` file that the C++ backend can load directly via `file:///`.
