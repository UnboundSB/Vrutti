# Folder: frontend

**Path**: `src/ui/frontend`
**Purpose**: Web frontend (Vite/TypeScript) for the IDE UI.

## Contents

### Subfolders
- **`src/`**: Root source directory of the Vrutti IDE containing all application code.

### Files
- **`Dockerfile.frontend`**: Docker container definition for reproducible Vite builds.
- **`index.html`**: Entry HTML file for the Webview2 UI.
- **`package-lock.json`**: Locked NPM dependencies tree.
- **`package.json`**: NPM manifest defining frontend dependencies and scripts.
- **`tsconfig.json`**: TypeScript compiler configuration.
- **`vite.config.ts`**: Vite bundler configuration (includes vite-plugin-singlefile).

### Files
- **`structure.md`**: Documentation describing the high-level purpose of items in this folder.
