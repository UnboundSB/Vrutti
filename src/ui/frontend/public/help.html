Vrutti IDE

Fast, native, and built for modern developers.

🚀 Getting Started

Welcome to Vrutti! You're looking at a next-generation native code editor powered by a C++ engine and a blazing-fast Lit web frontend.

  • Open a folder: Go to File > Open Folder... or simply use the file explorer on the left.
  • Command Palette: Press Ctrl + Shift + P to open the command palette and quickly search for files or commands.
  • Terminal: Press Ctrl + ` to toggle the integrated high-performance terminal.

✨ Key Features

  • Topological Git Graph: An interactive, hardware-accelerated SVG git visualizer. Click "Source Control" on the sidebar to view your repository history, drag to pan, and interact directly with commits.
  • Integrated Tasks: Vrutti seamlessly parses your project's `tasks.json`. Run them directly from the Terminal > Run Task menu.
  • Native Speed: By keeping heavy file-system watching, language servers, and IPC routing in C++, Vrutti maintains minimal memory overhead compared to traditional Electron editors.

🔧 Troubleshooting

If you encounter issues, here are a few things to try:

  • UI Looks Glitchy? The IDE uses WebGL for the terminal and Git graph. Ensure your graphics drivers are up to date.
  • Debugger Not Attaching? Ensure you have the Python/Node extension properly loaded. The native DAP client requires the `initialize` command which is handled automatically, but path mapping on Windows must match exactly.
  • Need more help? Visit our GitHub Issues page.
