# Directory: scm

## Purpose
Source control management components for visualizing and interacting with Git repositories.

## Files
- **scmModel.ts**: Defines the data structures and IPC contracts for Git source control management.
- **vrutti-git-graph.ts**: Interactive horizontal topological canvas for exploring Git commit history, zooming, panning, and branching.
- **vrutti-scm.ts**: Implements the Source Control sidebar tab for viewing staged, unstaged, and committed changes.
