# Folder: ext

**Path**: `src/ext`
**Purpose**: Node.js extension host scripts and IPC bridges for VS Code extensions.

## Contents

### Files
- **`api.js`**: Extension host API definitions mimicking the VS Code extension API.
- **`bootstrapper.js`**: Entry point for the isolated Node.js extension host process.
- **`ipc.js`**: Node.js side IPC handler for communicating with the C++ backend.

### Files
- **`structure.md`**: Documentation describing the high-level purpose of items in this folder.
