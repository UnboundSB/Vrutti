# Logos Directory

This directory contains the official branding assets and icons for Vrutti IDE.

## Files
- `icon.ico`: The standard Windows executable icon file. Used by the C++ window manager to set the window titlebar and taskbar icon.
- `favicon-16x16.png`: A 16x16 version of the Vrutti logo, optimized for small inline UI elements.
- `favicon-32x32.png`: A 32x32 version of the Vrutti logo.
- `logo-512x512.png`: A high-resolution master logo for splash screens and general branding.
