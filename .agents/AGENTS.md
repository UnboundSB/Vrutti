
# Git Workflow Rules
- **ALWAYS** commit and push changes individually, immediately after a file is changed.
- **NEVER** perform bulk commits or push multiple files at once.

## Immediate File Commits
Whenever you modify a file, you MUST immediately commit and push the changes for that specific file before making modifications to any other file or continuing with other tasks. Use a descriptive commit message that summarizes the changes made to that file.
